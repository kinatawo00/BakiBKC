# Acarraf logo animasyonu

Sitenin üst kısmındaki turuncu-siyah **acarraf** logosuna hareket verir:

1. Sayfa açılınca turuncu **"acar"** soldan kayarak gelir.
2. Siyah **"raf"** yukarıdan düşer, zıplayarak yerine oturur.
3. Her 4,5 saniyede bir "raf" yukarı fırlar, geri düşerken "acar" sarsılır ve logonun üstünden ışık geçer.
4. Fare logonun üstüne gelince logo büyür, "raf" zıplar.

Animasyon bitince logo orijinaliyle birebir aynı görünür. Masaüstünde ve mobilde çalışır.
Hareket azaltma ayarı açık olan ziyaretçilerde animasyon kapalı kalır.
Kod çalışmazsa sitedeki orijinal logo olduğu gibi görünmeye devam eder.

## Ekleme
`logo-animasyon.html` dosyasının tüm içeriğini kopyalayın ve
**Ticimax → Modüller → Script Yönetimi → Tüm Sayfalar** alanına, mevcut kodların **altına** yapıştırıp kaydedin.

Önizleme: `onizleme-logo.gif` (masaüstü), `onizleme-logo-mobil.gif` (telefon)
