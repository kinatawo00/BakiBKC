# Acarraf ana sayfa slider: Elbise Askılıkları

- **`askilik-slider.jpg`**: Ticimax'e yüklenecek dosya (1672 × 941, mevcut slider görselleriyle aynı ölçü).
- `sitede-onizleme.jpg`: Ana sayfada nasıl görüneceğinin önizlemesi.
- `askilik-slider.html`: Tasarımın kaynağı. Yazılar ve renkler bu dosyada değiştirilir.
- `export.js`: HTML'den JPG üretir: `node banner/export.js`
- `assets/urunler/`: acarraf.com'daki ürün fotoğrafları (beyaz, katlanır krom, lüks ayarlı askılık).
- `assets/fonts/`: Oswald ve Montserrat (SIL Open Font License).

Ticimax'e yüklerken slayt linki olarak "Askılık ve Stand" kategori sayfası verilmelidir.
