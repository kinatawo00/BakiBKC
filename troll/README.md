# Şaka: Logo devrilir

Logoya tıklanınca "raf" sallanır, devrilir, ekranın altına "BUM!" diye düşer, yuvarlanıp ekrandan çıkar.
Sonra yukarıdan düşüp yerine oturur ve şu mesaj çıkar:
*"Merak etme, bizim raflar bu kadar kolay devrilmez 😄"*

## Şimdilik sadece deneme modunda çalışır
- Açmak için: **acarraf.com/?troll=1** (o sekmede siteyi gezdiğin sürece açık kalır)
- Kapatmak için: **acarraf.com/?troll=0**
- Normal müşteriler hiçbir şey görmez. Logo eskisi gibi ana sayfaya götürür.
- Deneme modunda logoya tıklamak ana sayfaya gitmez, şakayı oynatır.

## Ekleme
Logo animasyonu koduna ihtiyaç duyar. `logo-devrilir.html` dosyasının tüm içeriğini
**Ticimax → Modüller → Script Yönetimi → Tüm Sayfalar** alanında **logo animasyonu kodunun altına** yapıştırın.

Önizleme: `onizleme-masaustu.gif`, `onizleme-mobil.gif`
