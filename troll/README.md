# Şaka: Logo devrilir

**Ana sayfada** logoya tıklanınca "raf" sallanır, devrilir, ekranın altına "BUM!" diye düşer, yuvarlanıp ekrandan çıkar.
Sonra yukarıdan düşüp yerine oturur ve şu mesaj çıkar:
*"Merak etme, bizim raflar bu kadar kolay devrilmez 😄"*

- Herkese açıktır.
- Sadece ana sayfada çalışır. Ürün ve kategori sayfalarında logo eskisi gibi hemen ana sayfaya götürür.

## Ekleme
Logo animasyonu koduna ihtiyaç duyar. Önce `logo-animasyon/logo-animasyon.html`, sonra bu dosyanın
(`logo-devrilir.html`) tüm içeriği **Ticimax → Modüller → Script Yönetimi → Tüm Sayfalar** alanına,
mevcut kodların altına sırayla yapıştırılır.

Önizleme: `onizleme-masaustu.gif`, `onizleme-mobil.gif`
